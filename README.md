# QR Code Generator

A simple web app that converts any HTTP/HTTPS URL into a QR code.

## Features

- Enter a URL
- Automatically adds `https://` if the protocol is omitted
- Generates a QR code containing the URL
- Scanning the QR opens the same URL
- Download QR code as PNG
- Copy the generated link
- Responsive design

## Run

Open `index.html` in a browser.

The app uses QRCode.js from cdnjs, so an internet connection is required to load the QR-code library.
